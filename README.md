# 🥷 CyberNinja – Multilingual Cybersecurity Training Platform

> A full-stack cybersecurity awareness and training platform designed to help users learn, practice, and improve their cybersecurity knowledge through interactive quizzes, simulations, and educational content.

## 📌 Overview

CyberNinja is a full-stack MERN application focused on cybersecurity awareness and education.

The platform provides users with interactive cybersecurity quizzes, learning resources, real-world attack simulations, phishing URL analysis, multilingual support, and progress tracking.

It also includes an administrative dashboard for managing platform content and users.

---

## ✨ Key Features

- 🎯 Interactive swipe-based cybersecurity quizzes
- 📚 Multiple cybersecurity categories and difficulty levels
- 🛡️ Phishing URL detection and risk analysis
- 🎭 Interactive cybersecurity attack simulations
- 🌐 Multilingual support – English, Hindi, and Marathi
- 🏆 Leaderboard and user achievements
- 📊 User dashboard with progress and performance statistics
- 👨‍💼 Admin dashboard with content management
- 🔐 JWT-based authentication and role-based authorization
- 🎨 Responsive cyberpunk-themed user interface
- ✨ Smooth animations using Framer Motion
